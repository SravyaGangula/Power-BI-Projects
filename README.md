# Power-BI-Projects

## 📌 Project Overview:
The dashboard is crafted to help business stakeholders track critical KPIs—Sales, Profit, and Quantity—across the Central, East, South, and West regions, with the ability to easily toggle between metrics and years.

## 📋 Problem Statement:
The challenge was to develop a solution that enables users to:
Filter by year and view data dynamically for Sales, Profit, or Quantity.
Compare current and previous year metrics, with clear year-over-year growth indicators.
Visualize monthly sales trends with sparklines featuring average lines for trend analysis.
Analyze sales distribution by state using an interactive bubble map and a sorted bar chart for quick state-by-state comparisons.

## ⚙️ Project Approach:
My approach included:
Requirement Gathering: Collaborating with stakeholders to identify key business needs and KPIs.
Data Preparation: Connecting, cleaning, and modeling the data for accurate analysis.
Dashboard Development: Creating complex DAX calculations, sparklines, maps, and tables for dynamic comparisons.
Insights Generation: Ensuring the dashboard delivers meaningful insights to drive data-driven decision-making.

## 🌟 Outcomes:
The resulting dashboard empowers stakeholders by:
Offering a clear view of sales performance across regions with easy access to trends.
Enabling swift identification of high and low-performing states through intuitive visualizations.
Providing a user-friendly interface with dynamic filtering, facilitating focused analysis on specific metrics.

This project allowed me to deepen my expertise in data visualization and analytics, and I'm excited to continue building impactful solutions!
